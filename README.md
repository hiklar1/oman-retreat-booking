# وِجهة — استراحات عُمان

واجهة عربية RTL ثابتة مستوحاة من تصميم «وِجهة» لاستكشاف نماذج استراحات عُمانية. الأسماء والأسعار والصور أمثلة توضيحية فقط. تتضمن الصفحة محاكاة لخطوات الحجز ومعاينة الدفع، لكنها لا ترسل حجوزات أو تجمع بيانات شخصية أو مصرفية ولا تخصم أموالاً.

## الموقع

ملفات الموقع في `site/`. لا يحتاج المشروع إلى خادم أو حزم بناء. البحث والتصفية ومحاكاة الحجز تعمل داخل المتصفح فقط، من دون API أو بوابة دفع. الصور التوضيحية مستضافة على Unsplash وتُحمّل من نطاق الصور الخاص به.

## النشر على GitHub Pages

سير عمل GitHub Actions في `.github/workflows/pages.yml` ينشر محتويات `site/` عند الدفع إلى فرع `main`. من إعدادات المستودع، افتح **Settings → Pages** واختر **GitHub Actions** كمصدر للنشر إذا لم يكن مفعّلًا بالفعل.
