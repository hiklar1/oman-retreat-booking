# وِجهة — استراحات عُمان

واجهة عربية RTL ثابتة مستوحاة من تصميم «وِجهة» لاستكشاف نماذج استراحات عُمانية. المواقع المصوّرة حقيقية في عُمان، لكنها لا تمثل الاستراحات الافتراضية المعروضة. تتضمن الصفحة محاكاة لخطوات الحجز ومعاينة الدفع، لكنها لا ترسل حجوزات أو تجمع بيانات شخصية أو مصرفية ولا تخصم أموالاً.

## الموقع

ملفات الموقع في `site/`. لا يحتاج المشروع إلى خادم أو حزم بناء. البحث والتصفية ومحاكاة الحجز تعمل داخل المتصفح فقط، من دون API أو بوابة دفع. صور عُمان مستضافة مجاناً على Wikimedia Commons؛ أسماء المصورين وتراخيص الصور وروابط المصدر متاحة في تذييل الموقع.

## النشر على GitHub Pages

سير عمل GitHub Actions في `.github/workflows/pages.yml` ينشر محتويات `site/` عند الدفع إلى فرع `main`. من إعدادات المستودع، افتح **Settings → Pages** واختر **GitHub Actions** كمصدر للنشر إذا لم يكن مفعّلًا بالفعل.
