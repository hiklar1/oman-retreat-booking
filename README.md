# مَرافئ عُمان

واجهة عربية RTL ثابتة لاستكشاف نماذج افتراضية لاستراحات في عُمان. الأسماء والأسعار والصور أمثلة توضيحية فقط؛ لا توجد حجوزات فعلية أو تواصل مع مالكين أو معاملات.

## الموقع

ملفات الموقع في `site/`. لا يحتاج المشروع إلى خادم أو حزم بناء. عوامل التصفية تعمل داخل المتصفح فقط.

## النشر على GitHub Pages

سير عمل GitHub Actions في `.github/workflows/pages.yml` ينشر محتويات `site/` عند الدفع إلى فرع `main`. من إعدادات المستودع، افتح **Settings → Pages** واختر **GitHub Actions** كمصدر للنشر إذا لم يكن مفعّلًا بالفعل.
