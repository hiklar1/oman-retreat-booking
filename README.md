# وِجهة — استراحات عُمان

واجهة عربية RTL ثابتة لاستكشاف استراحات عُمانية. الصور استرشادية والأسعار والمعلومات المعروضة غير ملزمة. تتضمن الصفحة معاينة تفاعلية للتواريخ والأسعار وخطوات الدفع، لكنها لا تستقبل حجوزات أو تجمع بيانات شخصية أو مصرفية ولا تخصم أموالاً.

## الموقع

ملفات الموقع في `site/`. لا يحتاج المشروع إلى خادم أو حزم بناء. البحث والتصفية ومعاينة الحجز تعمل داخل المتصفح فقط، من دون API أو بوابة دفع. صور المنازل العصرية مستضافة على Unsplash.

## النشر على GitHub Pages

سير عمل GitHub Actions في `.github/workflows/pages.yml` ينشر محتويات `site/` عند الدفع إلى فرع `main`. من إعدادات المستودع، افتح **Settings → Pages** واختر **GitHub Actions** كمصدر للنشر إذا لم يكن مفعّلًا بالفعل.
